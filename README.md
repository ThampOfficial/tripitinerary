# ทริปด้วยกัน (Trip Itinerary)

เว็บแอปวางแผนทริปกับเพื่อน (UI ภาษาไทย)

- แผนเที่ยวรายวัน เรียงตามเวลาอัตโนมัติ จัดลำดับเองได้
- แผนที่ Google ในหน้า พร้อมระยะทางและเวลาเดินทางจริงระหว่างจุด (เวอร์ชัน GitHub Pages)
- รูปอ้างอิงหลายรูปพร้อมคำอธิบาย ไฟล์ตั๋ว/เอกสาร
- ค่าใช้จ่ายล่วงหน้าและระหว่างทริป หลายสกุลเงิน เงินกองกลาง สรุปว่าใครเหลือจ่าย/ได้คืนเท่าไร
- ดาวน์โหลด itinerary เป็น PDF
- ชวนเพื่อนด้วยลิงก์หรือรหัสเชิญ แต่ละคนมีหลายทริปได้

## สองเวอร์ชัน โค้ดหน้าแอปชุดเดียวกัน

## ติดตั้งเวอร์ชัน GitHub Pages (ครั้งเดียว)

1. **สร้าง backend**
   - สร้าง Google Sheet ใหม่แบบว่าง ๆ → เมนู ส่วนขยาย → Apps Script
   - ลบโค้ดเดิม วางโค้ดทั้งหมดจาก `apps-script/Code.gs` แล้วกดบันทึก
   - เลือกฟังก์ชัน `setup` → Run → อนุญาตสิทธิ์ทั้งหมด (ถ้าขึ้น "Google hasn't verified this app" ให้กด Advanced → Go to …)
   - Deploy → New deployment → ชนิด **Web app** → Execute as: **Me**, Who has access: **Anyone** → Deploy
   - คัดลอก Web app URL (ลงท้ายด้วย `/exec`)
2. **เปิด GitHub Pages**: Settings ของ repo → Pages → Source: Deploy from a branch → `main` / root → Save
3. **เชื่อมกัน** เลือกอย่างใดอย่างหนึ่ง
   - วาง URL ใน `config.js` (`window.TRIP_API = '...'`) แล้ว commit ทุกคนที่เปิดลิงก์ใช้ได้ทันที
   - หรือเปิดหน้าแอปแล้ววาง URL ในหน้าตั้งค่าครั้งแรก (จำไว้เฉพาะเครื่องนั้น)

ถ้าแก้ `Code.gs` ภายหลัง: Deploy → Manage deployments → Edit → Version: New version → Deploy (URL เดิมใช้ต่อได้)

## ข้อควรรู้

- ข้อมูลเก็บในชีต `docs` แถวละ 1 รายการ (เป็น JSON) อย่าแก้ในชีตโดยตรง
- เพื่อนเห็นการแก้ไขของกันภายในประมาณ 8 วินาที
- ใครมี URL ของ Apps Script หรือรหัสเชิญเปิดทริปได้ ส่งเฉพาะเพื่อนร่วมทริป
- รูปที่อัปโหลดเก็บในโฟลเดอร์ "ทริปด้วยกัน - ไฟล์แนบ" ใน Drive และเปิดดูได้ด้วยลิงก์
- รายการทริปจำไว้ในแต่ละเครื่อง เปลี่ยนเครื่องให้กด "เข้าร่วมด้วยรหัส"
- ข้อมูลในเวอร์ชัน Claude กับเวอร์ชัน Google Sheet แยกกัน ไม่ซิงก์ข้ามกัน
