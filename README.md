# ทริปด้วยกัน (Trip Itinerary)

เว็บแอปวางแผนทริปกับเพื่อน (UI ภาษาไทย)

- แผนเที่ยวรายวัน เรียงตามเวลาอัตโนมัติ จัดลำดับเองได้ พร้อมผังเส้นทาง ระยะทาง และเวลาเดินทางระหว่างจุด
- AI ช่วยวางแผนที่เที่ยว ร้านอาหาร คาเฟ่ ที่พัก
- รูปอ้างอิงหลายรูปพร้อมคำอธิบาย ไฟล์ตั๋ว/เอกสาร
- ค่าใช้จ่ายล่วงหน้าและระหว่างทริป หลายสกุลเงิน เงินกองกลาง สรุปว่าใครเหลือจ่าย/ได้คืนเท่าไร
- ดาวน์โหลด itinerary เป็น PDF

## ไฟล์

| ไฟล์ | ใช้ที่ไหน |
| --- | --- |
| `index.html` | เวอร์ชันหลัก รันเป็น Claude artifact (ใช้ฐานข้อมูล การอัปโหลดไฟล์ และ AI ของ Claude) เปิดตรงจาก GitHub Pages จะขึ้นว่าให้เปิดใน Claude |
| `apps-script/Code.gs`, `apps-script/Index.html` | เวอร์ชัน Google Apps Script + Google Sheet มีแผนที่ Google ในหน้า และดึงระยะทาง/เวลาจริงจาก Google Maps วิธีติดตั้งอยู่ด้านบนของ `Code.gs` (เวอร์ชันนี้ยังไม่มี AI, PDF และหลายสกุลเงิน) |
